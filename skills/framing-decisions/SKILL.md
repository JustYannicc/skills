# Framing decisions

Separate a decision from how it is presented. Equivalent descriptions should not silently produce different judgments.

## Hold the decision constant

Identify the choice beneath its presentation.

Ask:

> **Would the judgment change if the same facts were presented differently?**

Test this with matched truthful frames. Keep the underlying choice fixed and change only how it is expressed.

If a new presentation changes what is available or makes one choice easier, it changes the decision itself. Analyze that change rather than calling it a framing effect.

## Find what survives the frame

Agreement across matched frames strengthens the judgment that remains stable. A reversal reveals frame sensitivity, not a stable preference.

Base the choice on what survives the tested frames. When the answer depends on values, make that dependence visible and let the decision-maker resolve it.

Stop when another truthful frame would not change the choice or when only the decision-maker's values can resolve the remaining sensitivity.
