# Handoff candidate checklist

**Scope:** issue #26, a universal Handoff successor that preserves exact
continuation and transfers responsibility only through explicit acceptance.

> **HUMAN REVIEW REQUIRED** — this task may produce a pushed draft PR, but it
> does not approve, merge, or close issue #26.

## Task checklist

- [ ] Bind the pinned upstream Handoff revision, license, retained behavior,
  changed assumptions, and public-safe provenance.
- [ ] Define one model-invoked Handoff job with exact state, Responsibility,
  Authority, rationale, evidence, uncertainty, dependencies, Continuation, and
  next-frontier preservation.
- [ ] Keep the outgoing owner responsible until an identifiable successor
  accepts the exact revision; never complete the parent Outcome.
- [ ] Degrade honestly without a recipient, return route, or required
  capability.
- [ ] Prove human, agent, session, service, waiting, rejection, stale-context,
  missing-capability, negative, and cross-domain behavior.
- [ ] Run focused proof, simplify once, one Sol High adversarial review, one
  separate Sol High resolution check, `pnpm evaluations:record`, and
  `pnpm validate` without weakening gates.
- [ ] Commit intentionally, push `codex/issue-26-universalize-handoff`, and open
  a draft PR linked to #26 with exact revision-bound evidence.
