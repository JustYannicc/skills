# Source archive

This directory preserves the public-safe material needed to author and audit the skill suite without reconstructing it from chat history.

## Read order

1. [`THINKING_IN_SYSTEMS_STANDARD.md`](THINKING_IN_SYSTEMS_STANDARD.md) — complete universalized method and current public authority.
2. [`SYSTEM_DESIGN_TEMPLATE.md`](SYSTEM_DESIGN_TEMPLATE.md) — reusable universal design template.
3. [`THINKING_IN_SYSTEMS_SKILL_DESIGN.md`](THINKING_IN_SYSTEMS_SKILL_DESIGN.md) — full repository, distribution, suite, setup, and authoring design.
4. [`../requirements/REQUIREMENTS_LEDGER.md`](../requirements/REQUIREMENTS_LEDGER.md) — every operative skill-suite requirement and its durable owner.
5. [`research/`](research/) — public-safe evidence reports supporting the method and distribution design.

## Preservation rule

Prefer retaining public-safe source material in this repository over deleting it during authoring. Trimming is a later, deliberate editorial decision. Do not silently compress an authoritative source into a summary and discard the complete universalized version.

The exact historical inputs are not committed because this is a public repository and those files contain personal policy, local paths, private configuration details, and context-specific examples. Their SHA-256 fingerprints are retained below so the universalization can be audited against an authorized private copy without disclosing it. This is a publication boundary, not permission to throw away the private originals.

Research notes are public-safe snapshots of the investigation that produced the standard. Private session inventories, personal tool audits, local-path reports, and context-specific case files are omitted; their transferable conclusions are present in the complete standard and requirements ledger. Cite the original public sources when producing user-facing documentation.

Credentials, private keys, employer-confidential material, and access tokens must never be preserved here.
