## Language

**Event**:
Any entry in the household calendar. Something discussed or intended but not entered in the calendar is not an Event in this scope.

- **Scope:** Every entry in the shared household calendar
- **Aliases:** None accepted
- **Avoid:** Using Appointment or Commitment as a generic replacement for Event

- **Relationships:** Appointment and Commitment are narrower kinds of Event in this household-calendar vocabulary
- **Status:** resolved
- **Accepted by:** household language owner, proposal household-language-p5
- **Evidence:** calendar-notes@notes-r14; family-conversation@conversation-r22

**Appointment**:
An Event arranged with another Actor. An Event without that arrangement is not an Appointment, even if a household Actor intends to attend it.

- **Scope:** Shared-calendar Events for which arrangement with another Actor matters
- **Aliases:** None accepted
- **Avoid:** Using Appointment for every Event, or using it as a synonym for Commitment
- **Conflicts:** Arrangement with another Actor and agreement to attend are different boundaries
- **Relationships:** Every Appointment is an Event; it is also a Commitment only when an Actor has agreed to attend
- **Status:** resolved
- **Accepted by:** household language owner, proposal household-language-p5
- **Evidence:** calendar-notes@notes-r14; family-conversation@conversation-r22

**Commitment**:
An Event an Actor has agreed to attend. A tentative or informational Event is not that Actor's Commitment until the Actor agrees to attend.

- **Scope:** Shared-calendar Events for which an Actor's accepted attendance matters
- **Aliases:** None accepted
- **Avoid:** Using Commitment for every Event, or using it as a synonym for Appointment
- **Conflicts:** Agreement to attend and arrangement with another Actor are different boundaries
- **Relationships:** Every Commitment is an Event; it is also an Appointment only when it was arranged with another Actor
- **Status:** resolved
- **Accepted by:** household language owner, proposal household-language-p5
- **Evidence:** calendar-notes@notes-r14; family-conversation@conversation-r22
