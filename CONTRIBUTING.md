# Contributing

This repository is in its design phase. Changes should preserve the following contract:

1. One skill owns one recognizable job with a distinct invocation boundary.
2. A skill must remain truthful when a referenced companion is not installed.
3. Public material is universal: no private configuration, personal policy, employer information, credentials, or machine-specific paths.
4. Every behavior change includes representative activation and outcome evaluations.
5. Upstream wording is reused only when its license and attribution are explicit; prefer independently written adaptations.

Before proposing a skill, read [AGENTS.md](AGENTS.md), [CONTEXT.md](CONTEXT.md), and the [architecture](docs/ARCHITECTURE.md).
